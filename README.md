# Instagram Bot

Selenium Instagram login + follow-followers demo.

## Setup
1. Copy `.env.example` → `.env` and fill credentials.
2. Install Selenium + python-dotenv (and ChromeDriver matching your Chrome).
   ```
   pip install selenium python-dotenv
   ```

## Run
```
python main.py
```

Selectors break when sites change UI; treat this as a learning demo.
